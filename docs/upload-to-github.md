# Save locally and publish to GitHub

## Your local project folder

The project is already saved at:

```text
C:\Users\castr\OneDrive\Documentos\GTM Intelligence LAB
```

Because this folder is inside OneDrive, it may also sync to your OneDrive account. To keep an additional local copy, copy the complete project folder to another location such as `C:\Projects\GTM Intelligence Lab`.

## Recommended: GitHub Desktop

Git is not currently available in the project terminal, so GitHub Desktop is the simplest route:

1. Install GitHub Desktop from [desktop.github.com](https://desktop.github.com/).
2. Open it and sign in to your GitHub account.
3. Use **File → Add Local Repository** and choose the project folder above.
4. If GitHub Desktop says this is not a Git repository, choose its option to create a repository in that existing folder. Keep the existing files.
5. Review the changed files. Confirm `.env`, `.venv`, and CSV files in `data/raw` are not listed for upload.
6. Enter a commit message such as `Build GTM Intelligence Lab portfolio app`, then select **Commit to main**.
7. Select **Publish repository**. Choose a repository name such as `gtm-intelligence-lab` and decide whether it should be public or private.

The `.gitignore` in this project excludes `.env`, Streamlit secrets, local environments, raw CSV data, and generated processed data. Do not remove those protections or upload customer data. Synthetic files can be regenerated by the app.

## Command-line alternative

After installing Git for Windows and restarting the terminal, run these commands from the project folder. Replace `<YOUR_GITHUB_USERNAME>` with your account name and first create an empty repository on GitHub (do not add a README there):

```powershell
cd "C:\Users\castr\OneDrive\Documentos\GTM Intelligence LAB"
git init -b main
git add .
git status
```

Before committing, check that `.env`, customer CSVs, and any API keys are not staged. Then:

```powershell
git commit -m "Build GTM Intelligence Lab portfolio app"
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/gtm-intelligence-lab.git
git push -u origin main
```

## Run and deploy

To run locally:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

For Streamlit Community Cloud, connect the GitHub repository and select `app.py` as the entry point. Add `ANTHROPIC_API_KEY` under the app's **Secrets** settings only if you want API-generated briefs. Never put the key in GitHub or in the README. Without the key, the app uses its local fallback brief.
